# Driver Drowsiness Detection System

## Project Overview
A computer vision-based system designed to identify signs of driver drowsiness using facial and eye features.

## Objectives
- Monitor eye movements and eye closure.
- Identify possible signs of driver fatigue.
- Generate visual alerts for prolonged eye closure.
- Support safer driving through early warnings.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- Computer Vision

## Working Principle
1. Capture video frames using a camera.
2. Detect facial landmarks and eye regions.
3. Analyze eye features to identify prolonged eye closure.
4. Display a warning when the configured detection condition is met.

## Expected Output
- Face and eye tracking through a camera.
- Eye-status monitoring.
- A visual drowsiness warning when the detection condition is met.
